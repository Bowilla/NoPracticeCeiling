# No Practice Ceiling Mod
Practice ceiling getting in the way of your training?\
Don't want to PB and fall before trying the next jumps?\
NoPracticeCeiling does what it says and let's you practice unhindered!

## Install
This mod is used with [MelonLoader](https://github.com/LavaGang/MelonLoader).\
You may also get this mod on [Thunderstore](https://thunderstore.io/c/beton-brutal/p/Beton_Bros/NoPracticeCeiling/).
